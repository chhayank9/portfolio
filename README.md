# Chhayank Kadwe - Personal Engineering Portfolio

An interactive, responsive portfolio website and printable resume highlighting my work in **Embedded Systems, IoT, AI/ML, and Electronics Engineering**.

🌐 **Live Demo (GitHub Pages):** `https://chhayank9.github.io/portfolio` (or your chosen repo name)

---

## 📸 Portfolio & Project Highlights

- **Photo & Profile:** Integrated portrait photo with direct link to printable ATS-friendly resume (`resume.html`).
- **IoT-Based Machine Health Monitoring & Predictive Maintenance System:** Highlighting actual custom PCB prototype with ESP8266 and ZMPT101B voltage transformer.
- **ESP32-Based Robotic Arm:** Featuring the 4-DoF automated robotic arm with servo coordination and embedded C/C++ firmware.
- **Star-Shaped Fractal Wideband Antenna:** Featuring 3D electromagnetic simulation in CST Studio Suite replicating IEEE ICORT 2021 research.
- **RAG-Based Q&A Chatbot:** Local vector retrieval with Ollama & Gemma LLM.

---

## ⚡ Tech Stack & Tools

- **Frontend:** Semantic HTML5, CSS3 (Custom variables, Dark/Light mode, Glassmorphism, Responsive Grid/Flexbox), Vanilla JavaScript (ES6+)
- **Icons & Fonts:** FontAwesome 6, Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)
- **Core Engineering Focus:** 
  - Embedded C / C++, Python
  - Microcontrollers: ESP8266 NodeMCU, ESP32, STM32 Blue Pill, Arduino
  - Cloud / Telemetry: Firebase Realtime Database, Wi-Fi, UART, I2C, SPI
  - Hardware: EasyEDA (PCB Design & Schematics), SMD/THT Soldering
  - AI / ML: Local RAG, Vector Embeddings, Ollama, Gemma, Random Forest
  - RF Simulation: CST Studio Suite (Antenna radiation pattern & S-parameters)

## 🚀 How to Run Locally

1. Clone or extract this repository:
   ```bash
   git clone https://github.com/chhayank9/portfolio.git
   cd portfolio
   ```
2. Open `index.html` in your web browser:
   - On Windows: Double click `index.html` or run:
     ```powershell
     Start-Process index.html
     ```
   - Or open `resume.html` and hit `Ctrl + P` to print or save your resume as a clean PDF!
